# Play Store Screenshot Review Checklist - TapGo

Gunakan checklist ini sebelum mengunggah screenshot ke Google Play Console.

## Security and Privacy

- [ ] Tidak ada password.
- [ ] Tidak ada access token, refresh token, API key, snap token, atau secret.
- [ ] Tidak ada nomor rekening pribadi penuh.
- [ ] Tidak ada nomor KTP, foto KTP, atau selfie dokumen.
- [ ] Tidak ada nomor HP user production yang lengkap.
- [ ] Tidak ada data bank pribadi tanpa sensor.
- [ ] Tidak ada alamat pribadi user.

## Data Quality

- [ ] Tidak ada data dummy yang membingungkan.
- [ ] Tidak ada label "demo", "simulasi", "dummy", "fake", atau "sample" yang terlihat.
- [ ] Tidak ada transaksi test yang terlihat seperti transaksi production asli tanpa konteks.
- [ ] Tidak ada angka bisnis palsu.
- [ ] Tidak ada klaim hasil tetap atau klaim finansial agresif.

## App State

- [ ] Tidak ada error popup.
- [ ] Tidak ada loading screen.
- [ ] Tidak ada skeleton loading yang belum selesai.
- [ ] Tidak ada empty state yang terlihat seperti aplikasi belum siap, kecuali memang screen itu bertujuan menampilkan empty state rapi.
- [ ] Tidak ada crash dialog.
- [ ] Tidak ada debug banner Flutter.
- [ ] Tidak ada keyboard menutup input penting.

## Visual Quality

- [ ] Screenshot tajam, tidak blur.
- [ ] Resolusi sesuai Google Play.
- [ ] Status bar rapi.
- [ ] Bottom navigation tidak menutupi konten.
- [ ] Tidak ada teks terpotong.
- [ ] Tidak ada overflow warning.
- [ ] Dark mode/light mode terbaca jelas.
- [ ] Branding TapGo terlihat konsisten.

## Legal and Compliance Tone

- [ ] Tidak ada klaim penghasilan pasti.
- [ ] Tidak ada narasi skema cepat untung.
- [ ] Tidak ada logo brand pihak ketiga tanpa konteks resmi.
- [ ] Tidak ada logo Midtrans pada feature graphic utama.
- [ ] Tidak ada klaim payment channel aktif jika masih menunggu aktivasi.
