# TapGo Quick Start Guide

Panduan cepat untuk mulai menggunakan TapGo.

## Langkah 1: Download TapGo

Unduh aplikasi TapGo dari link resmi atau Google Play jika sudah tersedia.

## Langkah 2: Daftar Akun

Buka aplikasi, pilih **Register**, lalu isi:

- nama lengkap
- nomor HP aktif
- password
- kode referral jika ada

## Langkah 3: Lengkapi Profil

Masuk ke menu **Akun/Profile** dan lengkapi data yang diperlukan, terutama jika ingin menggunakan fitur membership atau withdrawal.

## Langkah 4: Pilih Membership

Buka menu **Membership** dan pilih paket yang sesuai:

- Basic
- Silver
- Gold
- Platinum

Baca harga dan benefit sebelum melanjutkan checkout.

## Langkah 5: Bagikan Referral

Lihat kode referral Anda di dashboard/menu akun, lalu bagikan kepada calon pengguna lain.

Referral hanya tercatat jika kode dimasukkan dengan benar saat registrasi.

## Langkah 6: Pantau Bonus dan Transaksi

Cek dashboard, wallet, dan riwayat aktivitas untuk melihat:

- saldo wallet
- PPOB balance
- referral
- bonus yang sudah valid
- invoice dan transaksi
