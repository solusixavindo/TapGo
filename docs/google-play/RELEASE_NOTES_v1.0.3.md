# Release Notes - TapGo v1.0.3

Versi: `1.0.3+4`

Rilis kandidat TapGo untuk validasi Google Play sebelum upload Internal Testing.

Perubahan utama:

- Menyelaraskan versi aplikasi, Android build number, header API, dan tampilan About.
- Mengaktifkan kebijakan backup Android yang eksplisit untuk melindungi data sesi dan data finansial pengguna.
- Mempertahankan integrasi DOKU sebagai payment gateway utama dan Midtrans sebagai fallback yang masih dalam proses review.
- Memastikan URL compliance publik tersedia untuk Privacy Policy, Terms & Conditions, Refund Policy, Delete Account, dan Contact.
- Xendit tidak digunakan pada TapGo v1.0.
