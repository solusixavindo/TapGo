05 Worker Rekonsiliasi backend runtime default mati

  • Fail-closed: hanya berjalan bila PPOB_RECONCILE_ENABLED=true DAN PPOB_PROVIDER=digiflazz; terpasang di server.ts, bukan createApp, sehingga test tidak menyalakan timer.
  • Eskalasi: PENDING lebih tua dari ambang (proses mati sebelum dispatch / timeout) menjadi PROCESSING dengan penanda reconcile:digiflazz.
  • Inquiry: tiap transaksi non-final dicek ke provider dengan ref_id sama; error jaringan tidak mengubah status dan dicoba lagi siklus berikutnya.
  • Multi-instance aman: pg_try_advisory_xact_lock — kunci lepas otomatis saat transaksi berakhir, tanpa ketergantungan Redis.
  • Log hanya jumlah — tidak pernah referensi maupun nomor tujuan.

06 Security teruji

  • Kredensial Digiflazz backend-only; sign dihitung di server dan tidak pernah dikirim ke klien.
  • DIGIFLAZZ_WEBHOOK_SECRET terpisah dari API key (dikonfigurasi di tempat berbeda pada panel provider).
  • Webhook tanpa auth token — keaslian murni HMAC; rate limit mengikuti jalur webhook pembayaran.
  • Mode testing=true dipaksa di luar production — UAT tidak dapat menyentuh saldo seller nyata.
  • Status asing dari provider dilempar (fail-closed), tidak pernah ditebak sebagai sukses.

08 Aktivasi & Limitasi langkah manual owner

Langkah aktivasi produksi

  • 1. Isi DIGIFLAZZ_USERNAME + DIGIFLAZZ_API_KEY dari panel Digiflazz; daftarkan IP server.
  • 2. Set webhook https://api.tapgolion.id/api/v1/webhooks/ppob/digiflazz + secret → isi DIGIFLAZZ_WEBHOOK_SECRET.
  • 3. Isi provider_sku katalog dengan buyer_sku_code dari panel.
  • 4. UAT sandbox: PPOB_PROVIDER=digiflazz + DIGIFLAZZ_TESTING=true.
  • 5. Setelah lulus: PPOB_RECONCILE_ENABLED=true, DIGIFLAZZ_TESTING=false.

Limitasi (kejujuran)

  • UAT dengan kredensial Digiflazz nyata belum dilakukan — butuh akun buyer + deposit (posisi sama seperti DOKU pada R1: kode/test lengkap, notifikasi produksi pending).
  • Postpaid (PLN Pasca/BPJS) tetap nonaktif — alur inquiry inq-pasca/pay-pasca dicadangkan stage berikutnya.
  • Customer UI tidak berubah (backend-only stage).
