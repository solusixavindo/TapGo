Batasan yang Disengaja → Handoff R2.8

Provider nyata belum terhubung. Setiap order produksi pada R2.7 berakhir REFUNDED — ini perilaku yang benar: lebih baik gagal jujur dengan dana kembali penuh daripada menggantung dana pengguna. R2.8 mengganti NoPpobProviderGateway dengan provider asinkron (Digiflazz dsb.) + settlement via webhook/polling; status PENDING/PROCESSING/SUCCESS sudah dimodelkan dan diuji di domain.
  • Katalog masih seed statis; manajemen katalog via admin console → kandidat R2.9.
  • Mode demo Flutter (TAPGO_PPOB_DEMO_MODE=true) melayani katalog mini nol-network dan jujur mensimulasikan fail-closed.
